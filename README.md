Sizzle & Serve is a fast top-down kitchen rush game: run a tiny restaurant through a 150-second shift, grabbing ingredients from the pantry, chopping and grilling them, stacking dishes on the plating counter, and serving each order before its customer walks out.

## Run it

```sh
node serve.ts
```
